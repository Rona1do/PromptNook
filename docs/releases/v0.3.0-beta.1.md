Organize a batch of ComfyUI generations, keep the original graph, and compare the recipes behind your results.

[Try the browser workspace](https://rona1do.github.io/PromptNook/) · [Import and export guide](https://github.com/Rona1do/PromptNook/blob/v0.3.0-beta.1/docs/COMFYUI_EXPORT.md)

## New in this beta

- Batch import review for ComfyUI PNGs, workflow JSON, and A1111 text: inspect covers and generation data, select what to save, and skip duplicates by default. Errors stay visible; retry only saves unfinished entries.
- Original ComfyUI graph preservation and export, including FLUX and custom nodes. JSON and PNG imports keep their UI workflow or API prompt snapshot. Valid custom-only graphs are kept as drafts even when their nodes do not expose standard recipe fields.
- Side-by-side recipe and cover comparison with highlighted prompt, LoRA, and parameter differences. Privacy mode hides prompt text, notes, and images.
- Safer model matching: subfolders are respected and ambiguous filenames remain unresolved.
- Reliable browser save feedback: storage failures now produce an error and roll back unsaved changes; reads no longer rewrite the workspace.

## Compatibility and data

- Original export preserves the imported graph unchanged. It does **not** apply subsequent recipe edits. Models and required custom nodes must already be installed in ComfyUI.
- Recipe-based graph generation still supports checkpoint text-to-image only. An edited FLUX recipe is not yet rebuilt into a new FLUX graph. Imported API prompts remain API-format JSON rather than being converted to the UI workflow format.
- Desktop database schema upgrades from 5 to 6 to store graph snapshots. Existing recipes remain intact; the vault creates a pre-migration database snapshot. Graphs are included in revisions and verified backups. Older app versions cannot open schema 6; back up before upgrading.
- Browser backup format remains version 1 with an optional graph snapshot. Browser-local storage remains bounded by the browser's quota. Source graphs are user-imported content and can contain paths or node values; inspect them before sharing. App translation credentials remain excluded from browser backups.
- No new automatic network requests or analytics. Prompt translation remains opt-in.

## Windows unsigned preview

The `UNSIGNED.exe` asset is an **unsigned Windows x64 prerelease installer**. Windows may show SmartScreen or publisher warnings. SHA-256 checksums are provided in `SHA256SUMS.txt`.

This release is built in GitHub Actions after frontend tests, browser end-to-end tests, Rust formatting, Clippy, and Rust tests pass. Automated tests cover database migration, original graph preservation, recipe revisions, and backup restoration. Clean-machine installation, uninstall, upgrade from an installed older beta, cross-machine restoration, and image generation in a running ComfyUI instance have **not** been verified for this release. macOS and Linux binaries are not offered.
